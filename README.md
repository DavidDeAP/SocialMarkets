#  SocialMarkets

Plataforma colaborativa de análisis financiero donde los usuarios comparten y validan proyecciones de mercado.

---

##️ Stack Tecnológico

### **Frontend**
* **React.js + Vite**: Entorno de ejecución y construcción de alto rendimiento.
* **CSS3 Avanzado**: Implementación de *Glassmorphism* (efectos de cristal) y diseño responsivo.
* **React Router**: Gestión de navegación SPA y rutas protegidas.
* **Axios**: Cliente HTTP para consumo de API REST.
* **React Icons**: Librería de iconografía profesional (Feather Icons).

### **Backend**
* **Java + Spring Boot**: Core del sistema y lógica de negocio.
* **Spring Security + JWT**: Autenticación y autorización basada en tokens.
* **Hibernate / JPA**: Mapeo objeto-relacional y gestión de persistencia.
* **MySQL**: Base de datos relacional para almacenamiento de usuarios y proyecciones.
